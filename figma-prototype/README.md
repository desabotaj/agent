# TimeTracker — Прототипы для Figma

Wireframe и высокодетализированные SVG-прототипы приложения для учёта рабочего времени **TimeTracker**.  
Все экраны созданы на основе информационной архитектуры (IA) и готовы для вставки в Figma.

## Как вставить в Figma

### Способ 1: Копирование SVG-кода

1. Откройте нужный `.svg` файл в текстовом редакторе
2. Скопируйте всё содержимое (`Ctrl+A`, `Ctrl+C`)
3. В Figma на холсте нажмите `Ctrl+V`
4. SVG будет вставлен как группа векторных объектов

### Способ 2: Импорт файла

1. В Figma выберите **File → Place Image** (или перетащите файл)
2. Выберите `.svg` файл из нужной папки
3. Файл будет импортирован на холст

### Способ 3: Drag & Drop

1. Откройте папку с файлами в файловом менеджере
2. Перетащите `.svg` файл прямо на холст Figma

## Параметры экранов

- **Размер**: 1440 × 900 px (стандартный десктоп)
- **Боковая панель**: 260 px
- **Шрифт**: Inter (системный fallback: -apple-system, sans-serif)
- **Wireframe**: оттенки серого, простые формы
- **Hi-fi**: градиенты, тени, цветовая палитра (#4F6EF7 primary)
