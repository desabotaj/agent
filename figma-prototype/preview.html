TimeTracker — Прототипы

Wireframe и высокодетализированные прототипы для Figma. 16 экранов на основе информационной архитектуры.

Как вставить в Figma

  1. Откройте нужный .svg файл из папки wireframes/ или hifi/
  2. Скопируйте всё содержимое SVG файла (Ctrl+A, Ctrl+C)
  3. В Figma нажмите Ctrl+V — SVG будет вставлен как векторный объект
  4. Альтернативно: в Figma выберите File → Place Image и выберите SVG файл
  5. Каждый экран — отдельный файл 1440×900px (стандартный десктоп)
