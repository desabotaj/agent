# Figma prototypes

Готовые SVG-коды для вставки или импорта в Figma по IA продукта учета времени.

## Файлы

- `wireframe-prototype.svg` - wireframe-прототип всего продукта: вход, главное окно, текущая сессия, журнал времени, проекты/задачи, расширенный поиск, отчеты, планы/лимиты, подключения, профиль/устройства, справка и мини-карточка сессии.
- `high-detail-prototype.svg` - высокодетализированный desktop-прототип: главное окно с активной сессией, доска проектов/задач, журнал времени, отчеты/экспорт, план/лимиты, подключения/профиль/справка.
- `generate_figma_svgs.py` - генератор, которым можно повторно собрать оба SVG без внешних зависимостей.

## Как вставить в Figma

1. Откройте нужный `.svg` файл.
2. Скопируйте весь SVG-код.
3. В Figma вставьте код на canvas через `Ctrl/Cmd + V`.
4. При необходимости разгруппируйте импортированный объект и отредактируйте тексты/слои.

Альтернатива: перетащите `.svg` файл в окно Figma или используйте `File -> Place image...`.

## Основание для структуры

Прототипы собраны по IA:

- личный кабинет после входа;
- главное окно;
- поиск по данным учета и расширенный поиск;
- текущая сессия с задачей;
- журнал времени;
- проекты и задачи в структуре `Проект 1...N -> Задача 1...N`;
- отчеты и экспорт;
- план и лимиты;
- подключения;
- профиль, синхронизация устройств, уведомления и горячие клавиши;
- справка и политики данных;
- вынос текущей сессии в мини-карточку с комментарием к записи времени.

## Повторная генерация
