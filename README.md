# «Пространство» — кириллическая гарнитурная пара

Намеренно простой и немного неровный учебный шрифтовой комплект для
**варианта 1**: мобильное приложение по дизайну интерьеров для начинающих
дизайнеров.

## Состав

- `Prostranstvo Sans Regular` — основной интерфейсный шрифт;
- `Prostranstvo Sans Italic` — акценты, подписи и подсказки;
- `Prostranstvo Serif Regular` — заголовки и редакционные материалы;
- `Prostranstvo Serif Italic` — цитаты и эмоциональные акценты.

Готовые TTF-файлы находятся в `dist/`, презентация гарнитуры — в
`specimen/Prostranstvo-specimen.pdf`, описание проектного решения — в
`docs/design-passport.md`.

## Набор символов

В каждом файле оставлен минимальный набор: **только прописные русские буквы
`А–Я` без `Ё`**. Дополнительно присутствуют технически необходимые пробел и
служебный `.notdef`. Строчных букв, латиницы, цифр и пунктуации нет.

Контуры специально слегка неровные: точки сдвинуты по-разному, поэтому прямые
штрихи и округлые формы выглядят как аккуратная ранняя работа новичка.

## Характеристики

| Параметр | Prostranstvo Sans | Prostranstvo Serif |
|---|---|---|
| Класс | гротеск | переходная антиква |
| Пропорции | слегка узкие | нормальные |
| Контраст | малый | умеренный |
| Набор | только прописные А–Я | только прописные А–Я |
| Назначение | интерфейс, навигация, инфографика | заголовки, советы, статьи |
| Курсив | истинный, с изменёнными формами | истинный, каллиграфический |

## Сборка

Требуются Python 3, `fonttools==4.67.0`, `reportlab==5.0.1` и установленный
пакет Ubuntu `fonts-noto-core`.

```bash
python3 tools/build_fonts.py
python3 tools/build_specimen.py
python3 tools/check_fonts.py
```

В качестве открытой основы использованы контуры Noto Sans Display и Noto
Serif Display. Они отобраны, скомпонованы, перемасштабированы и перенастроены
для учебной системы «Пространство». Производное шрифтовое ПО распространяется
по SIL Open Font License 1.1; сведения приведены в `OFL.txt`.
